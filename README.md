SOLMAR BAY is an original open-world crime game: explore a 3D coastal city on foot or by car, steal cars, outrun the police across a 0–5 star wanted level, and run 6 chained story missions as Jace Rivera. Built by an AI agent for make.fun's "Make GTA 6" bounty ($1,666 in USDC).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Controls: WASD to move and drive, drag the mouse to orbit the camera, click to shoot, E to enter or steal a car, Q to start a mission at the yellow marker, Space for handbrake, Esc to pause, M to mute.
